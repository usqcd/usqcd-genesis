# USQCD Genesis brand assets

## Authoritative sources

`USQCD-GMlogoFinal.key` is the editable Apple Keynote master supplied by William
Detmold on 2026-10-17. `USQCD-GMlogo.pdf` is the corresponding vector reference
export. Preserve both files unchanged: edit the Keynote master when an approved
brand change is required, and use the PDF to verify exported geometry and
appearance.

## Web derivative

`usqcd-genesis-logo-light.svg` is a mechanically converted, tightly cropped SVG
for use on a white or very light background. The conversion preserves the
reference-export geometry and converts the embedded Helvetica Neue Bold glyphs
to vector paths, so the asset does not depend on a web font. The source PDF
contains no raster images.

The current source artwork includes white shapes used both as the slide
background and to create the opening in the Genesis rings. Consequently, this
SVG is intentionally identified as a light-background variant. Dark-background,
monochrome, stacked, and small-icon variants require separate visual review and
approval rather than automatic recoloring.

The principal blue in the supplied PDF is approximately `#004D80` in RGB.

Do not redraw, simplify, or rearrange the wordmark, Genesis rings, sweep, neural
network, or lattice when preparing additional formats.
